# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting Security Issues & Bypass Vectors

NeaCommand is designed to enforce strict command isolation, packet-level Brigadier tab filtering, and LuckPerms group synchronization. If you discover a bypass technique (e.g. namespace evasion, Brigadier packet leaks, or race conditions during asynchronous tab-completion), please notify us responsibly:

- **Email:** `milansanchz@gmail.com`
- **Subject:** `[NeaCommand Vulnerability] Description`
- **Details:** Please provide reproduction steps, server version (Paper/Folia), and relevant configurations.

Vulnerabilities will be addressed with high-priority patches within 48 hours.
